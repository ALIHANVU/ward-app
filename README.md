# Ward

Исламский помощник для Android: время намазов с азаном, Коран с чтецами и пословным разбором, хадисы, дуа и азкары, кибла и мечети рядом, ИИ-поиск по Корану и хадисам, редактор видео с аятами.

## Установка

1. Откройте раздел [Releases](https://github.com/ALIHANVU/ward-app/releases) и скачайте последний файл `Ward-*.apk`.
2. Откройте его на телефоне. Если Android спросит — разрешите установку из этого источника.

Нужен Android 7.0 или новее (64-битный телефон).
